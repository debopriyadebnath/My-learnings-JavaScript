## About

This repository is a collection of my JavaScript learning resources, code implementations, and practice exercises while following the **Chai aur JavaScript** series by [Hitesh Choudhary](https://github.com/hiteshchoudhary).

The focus is on understanding the language beyond syntax — exploring how JavaScript works, experimenting with different concepts, and developing the programming fundamentals required for modern web development.

Each module is organized to maintain a clear progression from foundational concepts to more advanced topics.

## Getting Started

To access the repository locally:

**1. Clone the repository**

```bash
git clone https://github.com/debopriyadebnath/My-learnings-JavaScript.git
```

**2. Navigate to the directory**

```bash
cd My-learnings-JavaScript
```

**3. Open in Visual Studio Code**

```bash
code .
```

**4. Execute a JavaScript file**

```bash
node filename.js
```

For DOM-related implementations, open the corresponding HTML file in a browser.
